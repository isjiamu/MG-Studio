# 导演与视觉方法

## 让形式服务内容

短宣传片常用「提出问题 → 展示变化 → 证据/体验 → 收束」；科普常用「疑问 → 熟悉现象 → 机制 → 反例/边界 → 回顾」。不要把固定七镜或十二镜强加给所有片子。

## 参考拆解

有视频时：记录每镜持续时间、视线落点、动效速度、进入/退出方式、相邻镜头沿用的对象和声音触发点。抽帧间隔按镜头密度选；高速段单看 0.5 秒抽帧会漏掉关键动作，应看转场前后连续帧。

色彩、字体、材质、构图和镜头运动分别描述。用明确规则替代「高级、大气、惊艳」：例如“温暖纸白底、黑字、单一朱红点色；标题靠左，最多两行；先拉长再收拢的遮罩转场”。风格名只是路标，实际帧优先。

参考只决定适合借鉴的视觉特征。不能由成片反推确切代码、模型版本、制作耗时或成本；推测与实测分别记录。

## 动效的因果关系

- 可选择贯穿对象，例如圆点、卡片、光线、字母。只有身份或语义连续时才让它从 A 变成 B；两种不同口径的指标不能因外形相似而无提示地互相变形。
- 主体动作先发生，次要元素延后；让注意力有顺序。不是所有元素同时淡入。
- 开始快、落点稳是常用选择，但重量、情绪和音乐会改变曲线。不要把“所有动作必须弹簧”写成审美定律。
- 容器变形时，旧内容先退场，新内容在足够空间形成后入场。不能让文字随容器被压扁。
- 连续形变保持质心、边缘或视觉语义中的至少一个连续锚点。硬切也可以很好，只要目的明确。
- 分开标注“入场、稳定阅读、离场”。阅读时间不包括飞入、变形、数字仍在变化或被遮挡的阶段。中文短标题可先留约 0.8–1.5 秒稳定区，解释句更长；用真实观看修正，不把数字当硬性公式。
- 避免在每拍硬塞一个事件。重拍、留白、延迟与收束共同建立节奏。

## 构图与版式

先测试最容易失败的中间状态：抓住物件、一次请求跨边界、数据正负变化或两段文字交接。再画 2–3 张代表整体变化的静帧与粗剪。好看的开场和片尾不能证明观众能看懂中间过程。

- 标题、主体与辅助信息只保留清晰的三级层次。
- 中文须检查真实字体、换行、标点、字重、长词和字符缺失。不要仅用英文模板换字。
- 画幅变化时重排位置、字号、标题换行与对象尺度。横转竖直接裁切只在主体本来就处于安全区且用户接受时使用。
- 品牌真实截图不等于把整屏缩到看不清；选关键区域，以局部放大、遮罩和标注展示。
- 纹理、渐变、粒子、阴影都可用，但每个效果必须服务视觉主次。无条件禁止某种风格同样会模板化。

## 科普额外要求

先把“观众要理解的机制”写成一句准确的话，再决定视觉。必要时核对领域一手材料；事实、简化和示意分开。坐标、箭头和颜色含义跨镜保持一致。数据图从真实数据生成，不能为了美观改比例。

## 音画关系

优先在实际音乐上做节奏表；程序配乐可共用 BPM 和 cue。强拍检测不等于每四个普通拍取一个，外部音乐可能有前奏、弱起和变拍。音效峰值应靠近动作发生点，而不只是音频文件起点。

无缝循环需要位置、速度、视觉密度和音频接缝共同连续；`t % duration` 只让时间回绕。首尾图像相同也不证明速度连续。

## 检查是否表达清楚

从 brief 写出 2–3 个具体问题，例如“第一次为什么走了更长的路”“哪一年变化最大”“主角在哪一刻决定行动”。指出成片中提供答案的时间段。如果答案只能在说明文档里找到，应调整画面或缩小本片目标。制作方自查只能说明证据是否出现，不能代替真实观众的理解测试。
