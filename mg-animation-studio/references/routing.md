# 路由：审美与精确如何配合

审美与科学/准确大多数时候**并不冲突**：把原理画得更有质感、把数据讲得更有节奏、把画面做得更有空间感，并不需要牺牲事实。路由的作用，不是在任何一路压抑审美，而是在**真正发生取舍时**（比如信息密度 vs 留白、示意表现 vs 精确刻度、自由技术栈 vs 跨机移植）给出清楚的判断依据。

## 路由一：表达重心（`film.json.route.emphasis`）

| 路由 | 适用情境 | 事实与精确怎么处理 | 美术与信息节奏怎么处理 |
|---|---|---|---|
| `aesthetic` 审美与感染力优先 | 品牌片、新品发布、概念宣传、艺术表达、设计宣言、故事短片；或用户明确提出“放开做 / 追求惊艳 / 审美优先” | 核心事实和真实数字不编造；原理与结构允许风格化或示意表现（必要时注明示意） | 给画面和情绪最高空间；精炼文案与指标，让每一拍都留得住印象；工程脚手架完全可选，可自由选用 Three.js / WebGL / DOM / SVG / Canvas 与定制音频 |
| `balanced` 平衡（默认） | 知识科普、产品原理拆解、财经/行业解读、技术架构 | 数字、单位、出处、因果、方向、先后严格准确，单一数据源驱动画面与文案 | 在保证观众看懂且不产生误解的前提下，把美术、材质、空间和节奏做到最好；视觉效果服务于理解与记忆 |
| `precise` 精确与读数优先 | 教学图表、可测量实验/数据播报、工程规范、合规材料 | 轴刻度、比例、缺测、正负基线与拓扑关系严格精确；不靠装饰干扰读数 | 美术在清晰的结构与网格之内建立高品位（字体、留白、色彩克制、微质感、优雅的节奏），同样追求出版物级的完成度 |

**遇到真冲突时的唯一标尺**：这个视觉处理会不会让观众**相信一件不真实的事**？
- 会误导事实 → 优先保真，换一种同样高级但不误导的表现手法。
- 不会误导事实 → 放心让审美和电影感主导，必要处用简洁小字标注“示意”。

**关于“看不见的精度”**：精确靠单一数据源（一份数据同时驱动图形和文字）、核对来源、以及定性正确的视觉关系来实现。除非任务明确要求像素级测绘，否则不必把迭代轮次消耗在观众肉眼根本分辨不出的像素对位脚本上——把精力留给构图、材质、光影和动态节奏。

## 路由二：视觉审片条件（`film.json.route.vision`）

| 条件 | 做法 |
|---|---|
| 当前环境**能看图** | 在风格帧、关键中间态、转场连续帧和最终成片阶段，真实打开高分辨率图片做导演式审片，以人眼观感推动修改 |
| 当前环境**不能看图** | 1. 优先借助宿主可用的视觉子代理或看图工具审阅风格帧与接触表；<br>2. 若无任何看图通道，在**风格帧阶段**停一次，把 2–3 张代表帧交给用户看一眼确认方向，再投入全片渲染；<br>3. 像素统计只用于核查黑帧、越界、缺图等基础硬错，不拿量测分数冒充审美验收；<br>4. 交付时如实写明未做视觉验收，并标注最值得人工查看的 3 个时间点 |

## 路由三：创作起点与技术媒介

- **起点自由**：有清晰创意时直接从本片的视觉世界动笔；需要参考工艺上限与不同媒介的实现方式时，可查阅 [高水准范例库](demos.md) 里的 4 支可运行 Demo。
- **媒介自由**：不预设“只能用 Canvas 2D”。开工前快速探测环境可用能力（GPU WebGL、本机与打包字体、摄影/分层素材、音频工具），选最能把本片做绝的技术路线：
  - 立体材质、折射、实时光影 → `capture:"dom"` + `gpu:true` + Three.js / GLSL
  - 精密工业质感、程序化微肌理与机械阻尼 → `capture:"canvas"` 纯 Canvas 2D
  - 实拍/渲染分层剖面 + 精密 SVG 图形/波形/排版 → `capture:"dom"`
  - 只要保持 `seek(t)` 确定性并交付真实 MP4，也可以在独立工程中自由组织代码。
