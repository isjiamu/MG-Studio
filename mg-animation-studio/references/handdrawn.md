# 手绘、拼贴与叙事

## 先定故事，再定笔触

在 brief 中确定：主角想要什么、做了什么、什么因此改变、结尾留下什么感觉。角色可以是人、纸鸟、线团或字母，但必须有选择与反应。用重复物件建立前后关系，例如被划掉的字→被收集的纸片→组成新图案。避免每镜完全重置舞台。

## 可复用的绘画层

| 层 | 实现 | 控制 |
|---|---|---|
| 纸感 | 固定种子的低频色差、细颗粒、稀疏长纤维三层 | 预生成一次；分别检查白天/夜景，深色背景上尤其要降低颗粒对比，避免像屏幕噪点 |
| 线条 | 路径沿法线轻微偏移、两次轻描、粗细变化 | 轮廓偏移小于特征尺寸；不要让文字与精密数字抖动 |
| 纸片/色块 | 不规则边缘、错位套色、有限阴影 | 保持同一光向与厚度；不用每层都加投影 |
| 角色 | body/head/limb/eye 独立局部坐标，旋转关节 | 固定比例；呼吸/眨眼/视线只依赖 t；动作前准备、动作后回稳 |
| 圈注 | 椭圆/曲线按路径长度写出 | 笔尖与路径同步；圈的是叙事重点，不是随机装饰 |
| 文字成形 | 在轮廓 mask 内排字，或采样字形/轮廓为粒子目标 | 保留可读主句，微字只作纹理；粒子 ID 固定 |
| 镜头 | 舞台坐标→相机平移/缩放→输出画布 | 字幕单独在屏幕坐标，不能跟场景缩得不可读 |

`lib/draw.js` 提供基础绘图与文本边界；`lib/handdrawn.js` 提供变粗细的双描线、斜线排笔、纸材质、分部件纸鸟及关节锚点。`src/story.js` 示范持续舞台、衔纸、落下、文字轮廓和星点连线。先让轮廓、折痕、排线形成手绘感，再少量加全屏纸纹。纸片上的颗粒应在物件局部坐标绘制，随纸片一起移动；夜景可加固定的低对比网点和墨色差，避免逐帧变化的全屏噪声。中文主句仍用清晰本地字体；“手绘”不等于不可辨认。

## 把角色动作写成因果

按本片动作选择需要的环节，例如搬运可以是 **注意 → 准备 → 接触 → 搬运 → 释放 → 回稳 → 反应**，不要求每个故事包含全部环节。先改变视线/头部，再移动身体；起跳前压低重心，飞行时收脚，接近支撑物时伸脚，落下后少量衰减回弹。翅膀与尾部的跟随应有先后，不能所有部件使用同一个正弦波。主体出现在角色另一侧时，实际调整头部朝向，不能只移动瞳孔却让角色一直背对重点；完整展示姿态和反应的意义大于增加动作数量。

事件前、事件中和事件后的状态应能对照。例如“遮雨使植物恢复”需要先看见植物受雨影响，再看见雨被真正遮住，最后看见恢复；如果初始姿态一直相同，就没有建立变化。无对白作品尤其要用可见动作和环境反馈提供原因，不能只在脚本里解释。

抓取物件时，从角色的局部锚点经过**全部**关节、缩放、呼吸、旋转与世界变换计算接触位置，物件与绘制代码共用结果。接触前物件保持自身运动逻辑，不为凑上抓握点而突然主动飞来；接触时可短暂停稳。释放后才切到独立轨迹，按需要继承释放点的速度。落脚后围绕实际画出的脚尖或脚底转动，不能用两个脚之间的虚拟点代替接触点；回弹用关节或挤压表现，固定支撑点不跟随身体上下漂移。

在画面中明确前后关系：容器背片 → 搬运物/粒子 → 容器前片 → 需要露出的角色。入袋、入罐不能只靠物件缩小或消失；应穿过开口并由前片遮住。

## 镜头和物件的连续空间

让主角、容器、道具在同一个世界坐标中持续存在，镜头通过插值跟随动作，字幕保持屏幕坐标。场景切换不默认重设角色位置和大小。选择保留哪一个对象作为观众的空间参照，明确上一镜带来了什么、下一镜接走了什么。

日夜变化可以通过纸边遮罩、局部照明和背景色完成；保留主体的位置。推近、拉远和摇移要围绕信息变化，而非每几秒自动缩放。经过型关键点保持速度连续，接触、落稳、阅读才按意图停住；逐段 ease-in-out 会在每个点归零，容易产生走走停停。`sampleKeyframes` 提供保形三次插值，重复位置可形成停留，适合示例中的连续轨迹；硬切、定格或弹性动作按各自意图处理。检查跟随镜头时，主物件和正在阅读的字条是否被边缘裁切，背景碎片是否移入字幕区。

## 确定性与动画节奏

线条可以每秒更新 6–10 次形成轻微重描感，**对象位移仍按输出帧率连续计算**。固定 `phase=floor(t*8)` 与线条 ID 派生扰动，逆序 seek 结果必须相同。不要把全片降为每秒 8 帧或每帧调用 Math.random。

形变有可追踪的对应关系：固定粒子或路径点数，用编号连接起点与终点；复杂物理先离线预计算。局部骨骼和镜头运动不能随着每次 seek 累积误差。

需要文字形变时使用固定 ID 与固定目标映射，保留相同粒子，不在转场时重新随机生成；目标图案由本片含义决定。按实际字体宽高选择采样间距与数量，尤其不能把全宽中文硬塞进比字形更窄的网格；减少重叠后，可用少量轮廓线或结构线补足识别。弧线路径、轻微分批延迟可以帮助变化，但要让完整轮廓停留足够久。检查 25%/50%/75% 的形变帧；角色、标签和装饰不能压住轮廓的重要部位。没有文字变形需求时，不必加入此效果。

先看准备/接触/释放/回稳姿态，再看连续动作。可通过 `window.MG.trace()` 暴露角色、相机、物件锚点，在抓取区间测距，并在事件前后密集采样找跳点。片尾回到开头时，要实际设计物件位置和速度，不能只声明 loop。

## 声音与情绪

先为叙事段落写声音意图，再排音符。例如：犹豫时低音区和不均匀留白，发现时旋律上行，守候时减少音符，生长时加入高音，展开时增厚和声与声场，结尾放慢并留尾音。这是可调整的配方，悬疑、喜剧和品牌片应有各自的曲线。

把接触、释放、入夜、苏醒、图案形成和收束放在画面与声音共用的事件表中。纸声、落下和亮起只选少量关键时刻。可让短音乐动机在后段重现并获得新的和声或结尾，使情绪发展有可识别的联系。调音符密度、音区、和声、力度、延音与留白，不能只更换 BPM、音量或给全片统一加鼓点。

`story` 使用标准库 Python 合成原创 felt/celeste/pad 近似音色：基频、不同衰减的泛音、柔和起音和立体声延迟，加少量滤波噪声纸声。`film.json.storyTiming` 与画面共用；音符和分段能量写入 `out/audio-source.json`。这是合成音色，不宣称实录乐器。最后检查实际 AAC 的情绪段落动态及尾音，不能只检查合成 WAV；数值检查不代表已听过。

## 可选单 HTML 交付

多文件便于编辑；用户明确要一个 HTML 时用 `python3 tools/pack_html.py` 输出 `out/standalone.html`，内嵌本工程的字体、配置、Canvas 绘制模块和当前配乐。要与成片听音一致，先从 MP4 直接提取 AAC 到工程内的 `out/preview.m4a`，再用 `--audio out/preview.m4a` 打包；默认原始 WAV 尚未经过最终混音。打开后可播放/拖动时间线。该文件是浏览器预览，不替代 MP4；内嵌后的大小和离线运行仍需检查。这个打包器只支持附带的命名导出模块，复杂外部依赖应使用正式 bundler。
