## 字体、制作工具与声音

- **字体**：`assets/NotoSansSC.ttf`，随 MG Studio 工程取得；按 SIL Open Font License 1.1 提供。原许可保存在 `assets/OFL.txt`，应随字体保留。
- **MG Studio**：[isjiamu/MG-Studio](https://github.com/isjiamu/MG-Studio)，使用提交 [`aa95c7ea262012661cd33611ca3fb6abc78269da`](https://github.com/isjiamu/MG-Studio/tree/aa95c7ea262012661cd33611ca3fb6abc78269da)。本次检出的仓库未见总项目 LICENSE；不推定为 MIT、Apache 或其他开源许可。字体许可仅适用于相应字体。
- **配乐**：`assets/music.wav`，本次原创程序合成 Synthwave，120 BPM；未使用现成歌曲、游戏原声或外部音频采样。
- **旁白**：`assets/voice.wav`，通过 [edge-tts](https://github.com/rany2/edge-tts) 调用 Microsoft Edge 在线 TTS 免费接口，音色 `zh-CN-YunxiNeural`；rate `+10%`，pitch `-5Hz`。声音为合成语音；免费接口不等同于对服务或音色权利的转让。

声音制作和时标信息见 `assets/AUDIO_README.md`。
