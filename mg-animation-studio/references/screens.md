# 巨幕与多画幅交付

巨幕是播放条件，不是某种固定美术风格。先取得：实际像素宽高、拼缝/异形区域、播放设备可解码规格、帧率、观看距离、声音条件、是否循环。未知时输出明确标注的概念预览和待确认规格；不冒称现场验收。

## 布局

- 依据像素图建立 safeInsets 与禁放区。`film.json.safeInsets` 为上下左右归一化边距，范围由校验器约束；它不能代替场地方提供的拼缝图。
- 关键信息离边、避拼缝；画面超宽时拆成语义分区，用流动线索关联，而非拉伸横版。
- 以实际视距检查最小文字，不能机械把手机 1080p 字号乘倍数。先只保留远处能读的一句标题、一个大数字或一个主图。
- 白场亮度、细线闪烁、摩尔纹、红色细字、快速闪烁与高频纹理都要在屏上看。屏幕模拟只用于准备。
- 无声环境以画面与短字完整表达；有音乐的母版仍应静音预览。明确要求无音轨时设 `audio.mode:"silent"`，清空音频 cues，跳过 `npm run score`；render / check / HTML 预览与打包均使用这一意图。不要对普通有声交付随意放松缺音轨检查。

## 流程

先低分辨率同宽高比 animatic，再按最终像素输出测试片，由场地方检查解码、色彩、拼接、掉帧、音频和循环。当前本地工具输出 H.264/AAC；如需 ProRes、HEVC、特殊色深或分屏同步，按播放系统另做转码与验证。

renderer 为 1920×1080 与 3840×1080 分别排版后，可用：

```bash
node tools/studio.mjs verify --size 3840x1080
node tools/studio.mjs stills --size 3840x1080
node tools/studio.mjs render --size 3840x1080 --tag ultrawide
node tools/check.mjs --dir out/ultrawide
```

这些是超宽演示规格，不代表所有 LED 屏的标准。竖屏或异形屏需要专门布局，不以尺寸参数自动拉伸。无缝循环需要设计镜头和音频接缝；默认 `loop:false`，不宣称无缝循环。
