# 数据、数字与架构

## 数据契约

先读文件，再设计图。附带 `lib/data.js` 接受 film.json 的 `dataset`：

```json
{
  "kind": "bar",
  "title": "季度处理量",
  "unit": "万次",
  "source": "项目方提供的已确认 CSV",
  "asOf": "2026-09-30",
  "illustrative": false,
  "domain": [0, 100],
  "rows": [{"label":"Q1","value":28},{"label":"Q2","value":46}]
}
```

示例数据必须 `illustrative:true`，画面显示“示意数据”。真实文件保留原始副本和来源/快照日期；CSV 先按实际列名、编码、日期和空值规则转为 JSON，不能静默将空值变成 0。工具验证有限数值、唯一标签、元数据和 domain 覆盖；这不等于核实外部事实。

`kind` 默认为 `bar`，还支持数据契约 `signed-bar` 与 `line`。`bar` 的 domain 从 0 起；`signed-bar` 包含 0，负数向零线的另一侧延伸；`line` 可非零起点。`linearScale(value, domain, range)` 统一计算位置，不接受 null。声明支持某类数据不等于已有 renderer 自动支持它：每个 renderer 用 `validateDataset(dataset,{kinds:[...],allowMissing:...})` 限定实际能力。

缺失值必须用 `value:null`，dataset 声明 `missing:"gap"`，该行有非空 `note`。例如 `{"label":"6月","value":null,"note":"未回传"}`。绘图代码先处理 null：柱图保留缺测位置和说明，折线断开路径，不连到下一个有效点。拒绝空字符串、NaN、越域或未支持的图形类型；不把一切异常转为 0。

- 单一指标显示值+单位+期间；比较同口径，比例用相同基线，增长率明确同比/环比。
- 柱图从 0 起，值的长度按同一 domain 算；折线可非零起点但应明显显示轴范围。
- 柱图从 0 长到真实值时，动画中间标签是插值；稳定状态显示输入原值。不要把插值帧作为实测时间点。
- 计数只承担变化感，关键结果保留稳定阅读区。小数位、千分位、正负号与单位固定。
- 缺测画断线或“无数据”；不自动补线。负值须实现围绕零线的组件；百分比、多轴、堆积和置信区间须按语义设计，不套正柱图。来源未定义的不确定度不可擅自命名为置信区间。
- 时间轴的间隔按真实时间差；排序变化要让同一条目的身份可追踪。

## 结构图契约

`graph.nodes=[{id,label}]`，`graph.edges=[{from,to,label}]`；校验 ID 唯一、端点存在，重复边不得无意叠加。

架构片先确定要追踪的一次事件。用大标题交代阶段，再点亮当前节点、沿方向移动数据包、揭示下一节点。边的方向表示语义；移动速度仅作示意，除非有真实时间数据。同步/异步、请求/响应、数据/控制流使用不同编码，并有图例。

必要模块保留关系，不为了对称虚构服务。镜头聚焦可以隐藏不相关模块，但交代上下文。截图里的拓扑与动画改画版要对照。涉及安全边界、权限或失败路径时，画出必要分支。

数字读取配置，不埋在绘图代码中。renderer 只声明并实现它真正支持的 kind；需要负值或缺测时实现对应画法；真实业务替换输入后重审图形和结论，不能只通过 schema 校验。

## 画得好看

数据图的表现力与准确并不冲突：清晰的层级、克制的色彩、舒展的留白、以及把抽象关系转译为贴合题材的形态或材质，都可以在完全忠实于同一份数据的前提下完成。宏观创作经验见 [craft-philosophy.md](craft-philosophy.md)。
